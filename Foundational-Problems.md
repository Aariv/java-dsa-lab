# The Foundational 100
## Phase 1: Arrays, Hashing and Prefix Computation

These establish lookup, counting, grouping, prefix processing, and in-place manipulation.

### Two Sum
Learn: Complement lookup with a HashMap.

### Contains Duplicate
Learn: Seen versus unseen using a HashSet.

### Valid Anagram
Learn: Frequency counting.

### Group Anagrams
Learn: Deriving a canonical grouping key.

### Top K Frequent Elements
Learn: Frequency map plus heap or buckets.

### Product of Array Except Self
Learn: Prefix and suffix products.

### Longest Consecutive Sequence
Learn: HashSet-based sequence detection.

### Majority Element
Learn: Frequency counting, then Boyer-Moore voting.

### Move Zeroes
Learn: In-place array transformation.

### Subarray Sum Equals K
Learn: Prefix sum plus HashMap.

### Range Sum Query, Immutable
Learn: Basic prefix-sum construction.

### Maximum Subarray
Learn: Kadane’s algorithm and local versus global optimum.
